# media-glance.nvim documentation

📚 Use media-glance.nvim to preview saved workspace files in a browser from Neovim. Local Markdown, Mermaid diagrams,
images, and other media share a file explorer and refresh when files change.

## Start here

Install the plugin and its matching binary through the [repository quick start](../README.md#install), then follow
[Preview your first document](tutorials/preview-your-first-document.md).

## Find the right help

| Section                              | What you will find                                                      |
| ------------------------------------ | ----------------------------------------------------------------------- |
| [Tutorials](tutorials/README.md)     | A guided preview with a diagram, an external edit, zoom, and cleanup.   |
| [How-to guides](how-to/README.md)    | Installation, workspace control, and recovery from errors.              |
| [Reference](reference/README.md)     | Configuration defaults, commands, Lua API, supported files, and limits. |
| [Explanation](explanation/README.md) | How ownership, watching, and local access work.                         |

For editor-local help, open `:help media-glance.nvim`. For a reproducible problem, read
[troubleshooting](how-to/troubleshoot.md) before opening an issue. Contributors should start at
[CONTRIBUTING.md](../CONTRIBUTING.md).
