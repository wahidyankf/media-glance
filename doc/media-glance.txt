1. REQUIREMENTS                                      *media-glance-requirements*

Neovim 0.10 or later on macOS or Linux, arm64 or amd64. A browser opens the
loopback viewer. Runtime needs no Node.js, Go toolchain, or resource scheduler.

Install the matching prebuilt binary explicitly with :MediaGlanceInstall.
Installation requires curl and either shasum or sha256sum. It downloads the
plugin's pinned release through HTTPS, verifies its SHA-256 checksum and
version/protocol, and atomically publishes the executable in the versioned cache.
An interrupted installation can leave an install.lock directory; after confirming
no installer is running, remove that directory before retrying.

==============================================================================
2. SETUP                                             *media-glance-setup*

The plugin creates commands but no default mappings. Example:
>
  local media = require('media-glance')
  media.setup()
  vim.keymap.set('n', '<BS>wvmo', media.open)
  vim.keymap.set('n', '<BS>wvml', media.list)
  vim.keymap.set('n', '<BS>wvmx', media.close)
<
Options:
>
  require('media-glance').setup({
    -- Defaults to vim.fn.getcwd(-1, -1), the global workspace directory.
    root = function() return vim.fn.getcwd(-1, -1) end,
    -- Optional executable override for an explicit source build.
    binary = '/absolute/path/to/media-glance',
    -- Optional state and cache overrides; defaults below.
    state_dir = vim.fn.stdpath('state') .. '/media-glance',
    cache_dir = vim.fn.stdpath('cache') .. '/media-glance',
  })
<
The default binary is cache_dir/v0.1.2/media-glance. Source builds must use the
matching release protocol. Installation fills cache_dir even when binary has an
override. A setup call replaces earlier options rather than merging them.
Configure options before starting a server.

==============================================================================
3. COMMANDS AND API                                  *media-glance-api*

:MediaGlanceOpen         Start this session's server or reopen its focused file.
:MediaGlanceList         List running servers. Enter opens; Escape cancels.
:MediaGlanceClose        List running servers. Enter stops; Escape cancels.
:MediaGlanceInstall      Explicitly download and verify the matching release.

Lua equivalents are open(), list(), close(), and install(). install() returns
path, nil on success or nil, failure on an expected installation failure.
shutdown() stops only this session's owned server through its ownership pipe.
setup(options) registers commands and VimLeavePre cleanup without starting,
building, or downloading a server.

Open, list, close, and shutdown return no result and report failures through
notifications. They use asynchronous jobs or callbacks; shutdown initiates cleanup
without waiting for exit. install() synchronously waits for its download and
verification steps, so Neovim can remain busy until installation finishes.

The picker uses vim.ui.select, so an installed UI provider may render the list.
Open and close picker rows show root | owner PID [this session] | :port.
Other sessions omit [this session]. Fuzzy search depends on your UI provider;
Telescope's ui-select supports filtering by workspace or port, native UI does not.
Telescope's media picker maps Escape to cancel in insert and normal modes.

4. BEHAVIOR                                          *media-glance-behavior*

Each Neovim session owns an independent server on the first free loopback port
between 57300 and 57399. Actual socket binding avoids races and occupied ports.
The server root stays fixed after startup even if Neovim changes directories.

Open and list selection use the current saved file inside the selected server's
root. The list captures the file before opening its picker. Files outside the
root, unnamed buffers, directories, and unavailable files fall back to root
README.md, then the file explorer. A named file with unsaved changes still opens
its saved disk copy; save first to include those changes.

The browser shows an explorer sidebar and previews Markdown, images, PDFs,
audio, video, and ordinary text. Markdown renders local images, Mermaid diagrams,
and supported math. Bundled assets keep these renderers available offline.
Filesystem updates from editors or agents refresh the browser without reopening.

Images and Mermaid have per-item controls: zoom from 25% to 800%, Fit to reset,
pan when larger than the viewport, and Expand for a modal view. Escape closes the
modal and returns focus. Live updates preserve navigation and relevant zoom.

The initial light/dark theme follows the system. Light mode / Dark mode changes
it and saves your choice for this browser origin. Mermaid follows the mode;
images retain their original colors. Expanded media includes the same control.
Theme changes preserve your file, scroll, zoom, and expanded view.
HTTP/HTTPS links use a native new-tab target without sending the viewer referrer.
Browser preferences can choose a window instead. Email links keep mail behavior.
A bundled eye icon identifies the viewer tab.

Normal Neovim exit closes its server; owner death and ownership-pipe EOF also
stop it. A living suspended Neovim owner keeps its server. Listing another
session's server does not transfer ownership. Closing a chosen server uses its
validated instance identity rather than killing an arbitrary process ID.

The viewer binds only to loopback, authenticates token routes, and confines file
access to canonical workspace paths. Raw Markdown HTML is escaped and document
scripts do not run. Keep viewer URLs and registry files private: their tokens
authorize access to workspace files. Remote images can contact external hosts.

==============================================================================
5. LIMITS AND TROUBLESHOOTING                         *media-glance-limits*

Markdown (.md and .markdown) and ordinary UTF-8 text previews are limited to
2 MiB. Larger text, invalid UTF-8, and binary files use a download view. Image,
PDF, audio, and video extensions have separate preview handling and rely on
browser format/codec support. Images and Mermaid support independent zoom;
audio, video, and PDF use browser controls. Ordinary Markdown has no standalone
math renderer; supported math labels belong to Mermaid syntax.

Local links and images resolve relative to their Markdown document. Leading
slashes resolve from the workspace root. Traversal and outside-root symlinks
are refused. Explorer omissions (.git, node_modules, .cache, worktrees) affect
navigation; they do not restrict authenticated access to known file paths.

Live updates watch the selected file, local referenced assets, and expanded
folders with their ancestors, bounded to 256 directory paths per browser stream.
Watching does not recursively cover every workspace file. At that limit, reduce
expanded folders or reload. Saved external edits and atomic replacements refresh
the browser. Closing the browser leaves the server running until its owner exits
or you stop it. Discovery requires a shared state_dir.

For errors, inspect :messages and the browser status. If the binary is missing,
run :MediaGlanceInstall or check your binary override. Confirm the root exists,
state/cache paths are writable, and ports 57300-57399 are available. Readiness
times out after 30 seconds. List and stop subprocesses time out after 10 seconds.
Each installer download has a 10-second connection timeout and 60-second limit.

Full guides, reference, and a first-preview tutorial:
https://github.com/wahidyankf/media-glance/blob/main/docs/README.md

Report reproducible issues with platform, Neovim version, plugin tag or commit,
error, and synthetic steps. Remove URLs, tokens, credentials, and private
workspace content.
